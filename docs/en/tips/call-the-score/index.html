Tip #11 · Rules · By Thierry Garot, pickleball player

Call the score out loud

In shortIn doubles, the score has three numbers and everyone gets lost. Calling it before each serve prevents arguments.

The server calls their score, then the opponents', then their server number: "4-2-1". The game starts at "0-0-2".

Tip: when your team's score is even, your team's first server should be on the right. If not, something's wrong.

Try this: For a whole game, each player calls the score when it's their turn to serve.
