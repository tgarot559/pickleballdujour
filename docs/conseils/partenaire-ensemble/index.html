Conseil n°17 · Double · Par Thierry Garot, joueur de pickleball

Bougez comme si vous étiez attachés

En brefEn double, imaginez une corde de trois mètres entre vous et votre partenaire. Quand l'un se déplace, l'autre suit.

Si votre partenaire est tiré sur le côté, glissez vers le centre pour boucher le trou. Si vous montez, montez ensemble. Une équipe décalée, un joueur devant, un derrière, ouvre un boulevard en diagonale.

À essayer : Faites un set où vous devez garder votre partenaire à côté de vous, jamais devant ni derrière.
